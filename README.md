# AJAY NXT 3D Portfolio

A React + TypeScript + Three.js portfolio customized for AJAY NXT.

## Details included

- Ajay Saini / AJAY NXT branding
- Website, WhatsApp, Instagram, LinkedIn, email and phone links
- Web, app, admin system, video editing and visual design services
- Diamond Restaurants, Rajmahal Palace, demo portfolio and Move To Go work cards
- SEO title and description for ajaynxt.com

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
